## 💻 Установка на Windows

### Шаг 1: Установка Python

1. Перейдите на [python.org](https://python.org)
2. Скачайте **Windows installer (64-bit)** для Python 3.11+
3. **ВАЖНО**: При установке поставьте галочку **"Add Python to PATH"**
4. Проверьте установку:
   ```powershell
   python --version
   # Должно показать: Python 3.11.x
   ```

### Шаг 2: Создание папки проекта

Откройте **PowerShell** (Win + X → Windows PowerShell):

```powershell
cd C:\
mkdir bzd_bot
cd bzd_bot
```

### Шаг 3: Скачивание файлов

Скопируйте все файлы проекта в папку `C:\bzd_bot\`.

### Шаг 4: Автоматическая установка

```powershell
.\setup.ps1
```

Скрипт автоматически:
- Создаст виртуальное окружение
- Установит все зависимости
- Создаст необходимые папки
- Создаст шаблон `.env`

### Шаг 5: Настройка .env

Откройте файл `.env` в **Блокноте** или **Notepad++**:

```
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
ADMIN_IDS=ВАШ_TELEGRAM_ID
```

**Как получить BOT_TOKEN:**
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

**Как узнать свой Telegram ID:**
1. Напишите [@userinfobot](https://t.me/userinfobot)
2. Получите свой ID
3. Вставьте в `ADMIN_IDS`

## 🚀 Запуск

### Через run.bat (рекомендуется)

```powershell
.\run.bat
```

### Через PowerShell напрямую

```powershell
# Активируйте окружение (если не активно)
.\venv\Scripts\Activate.ps1

# Запустите бота
python -m bot.main
```

### Остановка

Нажмите **Ctrl + C** в окне PowerShell.

## ⚠️ Важные замечания

1. **Это демо-версия** — используется mock-данные БЖД (5 маршрутов)
2. **Оплата эмулирована** — реальная интеграция требует API платёжной системы
3. **Для продакшена** — замените `MemoryStorage` на `RedisStorage`
4. **Уведомления** — работают через APScheduler (проверка каждые 10 минут)
